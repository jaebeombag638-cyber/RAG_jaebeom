# 제주 상점 RAG 실습

학습 설명·실행 순서·전체 코드는 [Rag실습.md](Rag실습.md)에 있습니다.

GPT Work에 문서를 첨부하고 `이 문서의 튜터 시작 규칙대로 0차시를 시작해줘.`라고 입력하면 문서 길찾기부터 공부할 수 있습니다. 전체 코드를 한 번에 읽을 필요는 없습니다.

아래는 설치와 전처리를 마친 현재 PC의 화면 실행 명령입니다. 새로 받은 프로젝트라면 [루트 안내](../README.md)의 설치·검사를 먼저 하고 학습 문서 §10에서 원본 전처리를 진행하세요.

```powershell
cd C:\RAG_jaebeom
.\.venv\Scripts\python.exe -m streamlit run practice\app.py --server.address 127.0.0.1
```

기본 화면은 데이터 준비 미리보기입니다. ES 검색·LLM 생성은 연결 후 별도로 검증합니다.
API 키는 `.env`에 빈 칸으로 준비했습니다. 실제 키를 입력하기 전에는 답변 생성을 보류합니다.
